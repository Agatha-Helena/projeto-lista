# projeto-lista

## Descrição
Projeto direcionado a matéria de 'Projetos'. Nosso projeto conta com a expectativa de proporcionar uma lista de apoio para estudantes de escolas e faculdades, se baseando nas tarefas pendentes de acordo com a matéria.

## Objetivos
- Proporcionar maior organização diária para quem usa o aplicativo;
- Praticar os ensinamentos realizados em sala de aula;

## Ferramentas utilizadas
- Expo Go (Ambiente de execução);
- VS Code (Ambiente de codificação);
- Claude (Ferramenta de IA);
